## 환경과 한계

- 로컬 개발 서버: `http://127.0.0.1:5193`
- 실제 `pwa/dist` 미리보기: `http://127.0.0.1:5194`
- 격리된 Chrome 브라우저 컨텍스트에서 실제 로그인·OTP 화면을 사용하고, 서버 응답은 합성된 검수 데이터로 대체했다. 인증 저장소 직접 주입은 사용하지 않았다.
- 실제 운영 계정 로그인, 실제 OTP·알림 발송, Notion 데이터 수정, 동의서 제출, 결제·환불은 수행하지 않았다.
- 브라우저 MCP의 기존 프로필 잠금 때문에 별도의 Playwright Chrome 컨텍스트로 검수했다. 다른 사용 중인 브라우저는 종료하지 않았다.
- 이 기록은 배포 전 UI 검수 결과다. 배포 완료 여부와 운영 버전은 별도의 배포 기록을 따른다.

## 배포 후 운영 진입 화면 확인

`v2.48.0` 배포 후 실제 `https://tiantian-chinese.pages.dev`의 강사 `/#/home`과 학생 `/personal`을 각각 390px·1280px에서 확인했다.

- 4개 화면 모두 HTTP 200, 실제 배포 진입 번들 `/assets/index-CVzszwV4.js`와 일치했다.
- 강사 비밀번호 입력·로그인 버튼과 학생 코드 입력 화면이 정상 표시됐다. 모바일 스크린샷도 직접 확인했다.
- 가로 넘침, 런타임 오류, 운영 사이트 자산 오류, 업무 변경 요청은 모두 0건이었다.

- 첫 시도는 sandbox 네트워크 제한으로 `ERR_NETWORK_ACCESS_DENIED`가 발생했다. 같은 읽기 전용 검수를 네트워크 허용 환경에서 다시 실행해 통과했다.
