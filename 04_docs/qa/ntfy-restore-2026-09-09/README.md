- 기준: 6894522(v2.46.7). 세션 10개 커밋 역적용, ntfy 상세 전송/인증된 알림함 조회만 추가 복원. 업데이트 전달용 버전 2.47.10.
- PWA build 성공, 389 tests/41 files, 디자인 ERROR 0/WARN 0. Worker 288 tests/21 files, 자동화 ntfy 15 tests 통과.
- 실제 로컬 Chrome http://localhost:5180 에서 강사 홈/설정/알림 및 학생 본인 확인 화면을 확인. 알림 fixture 원문 표시, 푸시 설정/진단/상세 팝업 제거, 가로 넘침 없음, 학생 인증 게이트 유지. SW에 push-sw.js import 없음.

- 업무 제목/본문/줄바꿈은 복원. 기존 접근 토큰 링크와 기존 상담 생성부의 이름/전화/카카오ID 마스킹은 유지. 공개 ntfy 토픽 주소를 아는 사람은 업무 원문을 읽을 수 있음.
