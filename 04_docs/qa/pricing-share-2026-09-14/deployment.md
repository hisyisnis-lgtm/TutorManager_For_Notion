## 사용자 요청과 반영 범위

강사앱 설정의 수강료 안내 링크 복사를 복원했다. ‘비공개’는 **검색 비노출·직접 링크 공유용**을 뜻하며 로그인 보호가 아니다. 링크를 받은 사람은 인증 없이 원래 수강료 안내를 열 수 있다. 신규 인증 게이트나 공유 토큰을 만들지 않았고 기존 수강료 조건을 유지했다.

공개 홈페이지·공식 웹·게임·공개 메뉴에는 가격표와 공유 링크를 추가하지 않았다. `/pricing`의 OG 정보와 `noindex, nofollow`를 유지하며, 가격표 코드는 전용 `PricingPage` 청크로 지연 로딩하고 일반 앱의 사전 캐시에서 제외했다. 공개 가격 검사는 해당 PWA 청크 하나만 조건부 허용하고 나머지 앱·공식 웹의 가격 노출을 계속 차단한다. 이전 세대의 가격 전용 청크도 자산 보존 대상에서 제외한다.

배포 커밋은 14개 소스·설정·테스트 파일과 2개 검수 결과 파일로 한정했다. 공유 작업 트리의 다른 변경을 보존했다. Worker, D1, 공식 웹과 독립 게임은 이번 수정으로 변경하거나 재배포하지 않았다. Worker는 `2018e22c-8392-49cf-bdb3-255d65ff4b68`를 유지한다.

## 검증

- 도구 회귀 22개, PWA 최종 CI 전체 65파일 558개 테스트 통과. lint, build, 디자인 감사 ERROR 0 / WARN 0 및 공개 가격 검사 통과.
- 최초 로컬 전체 검사에서는 552개 통과, 인증 2개·공지 3개가 기본 5초 제한에 도달했다. 설정의 복사 버튼 기대 개수 3→4는 실제 복원 화면에 맞게 수정했다. 이 3개 파일을 단일 작업자와 30초 실행 제한으로 재검증해 24/24 통과했으며, 제품 동작이나 테스트 assertion을 타임아웃 회피 목적으로 완화하지 않았다. 최종 원격 전체 검사도 통과했다.
- 실제 빌드의 로컬 브라우저와 운영 Pages 모두 390/1280px에서 강사 설정→복사 주소 `/pricing`→인증 없는 수신자 가격표 표시를 확인했다. 소개/가격 탭과 상담 이동, 모바일 하단 접근, 가로 넘침 없음, 런타임 오류·예상 밖 요청 0을 확인했다.
- 일반 학생 진입과 강사 설정에서는 가격 청크를 읽지 않고, 수강료 페이지에 들어갈 때만 읽는 것을 확인했다. 강사 로그인은 격리된 HTTP 응답으로 검수했으며 실제 OTP·업무 저장·알림 발송은 실행하지 않았다.
- Cloudflare 로컬 라우터와 운영/고유 URL 모두 `/pricing` 200, `/pricing.html` 308→`/pricing`, `/pricing/` 302→`/pricing`를 확인했다. 최종 HTML은 `/#/pricing`으로 연결되고 `X-Robots-Tag`와 HTML 메타에 `noindex, nofollow`가 있다. 공식 수업 안내로 보내는 이전 외부 이동은 제거됐다.
- 기존 정확한 옛 혼합 JS·이미지 4개 주소의 302 차단 규칙은 유지했다. 기존 포괄 SPA rewrite는 Wrangler가 무한 루프 규칙으로 무시하지만 기본 SPA fallback과 정적 수강료 HTML 우선 응답은 실제 검사에서 정상이다. 이와 무관한 라우팅 정리는 범위에 추가하지 않았다.
