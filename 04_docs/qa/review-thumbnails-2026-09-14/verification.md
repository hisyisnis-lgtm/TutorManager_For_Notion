# 공식웹 후기 썸네일 검수

기존 블로그 후기 3개에 원문 OG 이미지를 표시한다. 기존 공개 이미지 프록시를 사용하며 이미지가 실패하면 대체 아이콘을 유지한다.

- Astro 빌드 10페이지 성공. 실제 로컬 브라우저 390×844 / 1280×900에서 이미지 3개 로드, 원문 버튼 44px, 가로 넘침 0, 콘솔 오류 0을 확인했다. 루트 에이전트가 화면과 원격 이미지 응답을 직접 검수했다.
- 현재 운영 기준은 후속 게임 배포 84da1323-bcb4-432f-92ed-55e93baf4951. 937파일 중 후기 HTML 하나만 수정하고 CSS 하나만 추가했다. 나머지 936파일과 기존 footer는 바이트 동일하다.
- 가격 12파일, 게임 24파일, 헤더·리다이렉트·사이트맵을 그대로 보존했다. PWA·Worker·DNS를 배포하거나 변경하지 않는다.
- CSP 이미지 예외는 후기 HTML의 기존 Worker /og-proxy/image 정확 경로만 허용한다. 인라인 스크립트 5개와 스타일 1개의 CSP 해시, 전체 공개 가격 검사를 통과했다.
- 공유 site 전체가 미추적 작업 중이므로 승인된 소스 2개만 source-snapshot에 보관하고, 배포는 현재 운영 stage에 필요한 후기 산출물만 조립한다.

실제 배포 결과는 deployment.md에 기록한다.
