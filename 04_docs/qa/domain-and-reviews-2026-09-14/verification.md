# 공유 수강료 도메인·공식웹 후기 메뉴 검수

## 확정 범위

- 강사앱·학생앱의 기존 주소와 인증·기록 저장 방식을 유지한다.
- 수강료 공유 주소는 `https://tiantianchinese.com/pricing/`. 강사 설정에서 이 절대 주소를 복사한다.
- 수강료 페이지의 소개 탭을 제거하고 기존 가격·조건을 보존한다.
- 수강생 후기는 **공식웹 상단·모바일 메뉴**의 `/reviews/`로 추가한다. 가격표의 탭이 아니다.
- 공식웹·게임 메뉴와 사이트맵에 수강료 링크를 추가하지 않는다. 공유 페이지와 자산에 noindex,nofollow를 적용한다. 링크로 여는 안내 페이지이며 로그인으로 차단하는 설계는 아니다.

## 구현과 산출물

- PWA `PricingPage`를 사용하는 별도 React 진입점과 `vite.pricing.config.js`를 추가했다. `npm run build:pricing`으로 `/pricing/` 전용 산출물을 만든다. 앱 라우터·인증·서비스워커를 가져오지 않는다.
- 기존 공유 헤더와 히어로의 로고 경로는 Vite BASE_URL을 따른다. 기존 PWA에서는 여전히 `/`이고, 독립 가격표에서는 `/pricing/`이다.
- 실제 블로그 후기 3개의 제목은 기존 운영 `/#/intro`의 표시된 후기 카드에서 확인했다. 새 API나 이미지 요청 없이 원문 링크와 정적 제목을 사용했다. 짧은 후기 2개는 기존 공식 수업 안내에 있던 내용이다.
- 공식웹은 전체 미추적 작업 소스를 배포하지 않는다. 운영 `03f92a8a-b9b0-4aca-ad0e-4f0bd8c5a3e4`의 920파일을 기준으로 Header/Footer 메뉴·새 후기·공유 가격표만 조립한다.
- 조립 중 과거 공개 문구와 미사용 checkout 청크가 가격 검사에서 발견됐다. 교재의 ‘출간 일정과 가격’을 ‘출간 일정’으로, 게임 목록의 ‘PC · 모바일 · 무료 플레이’를 ‘PC · 모바일’로 정리한다. 미참조 `/_astro/WorkbookCheckout.R5WACr9n.js`는 새 산출물에서 제외하고 정확한 옛 주소를 `/books/`로 302 이동시킨다.
- 조립 디렉터리: `C:/development/TutorManager_For_Notion/.tmp_qa/pricing-domain-release-20260914/`. 배포 매니페스트·원본과의 비교·선별 조립 스크립트·사이트 소스 스냅샷을 보관한다.

## 실제 브라우저

사용 가능한 CUA 인앱 브라우저로 검수했다. 이미지와 메뉴 상태를 실제 화면에서 확인했다.

- `http://127.0.0.1:5195/pricing/`: 390px·1280px에서 가로 넘침 없음. 장식 로고 누락 1건을 수정한 뒤 모든 이미지 로딩 확인. 소개·후기 탭 없음. 하단 버튼과 마지막 푸터 접근 가능.
- 가격표 상담 버튼 클릭 → 기존 카카오 채널의 로그인 화면으로 정상 이동. 계정 입력·상담 제출은 하지 않았다.
- `http://127.0.0.1:5196/`: 데스크톱 홈 상단 메뉴 클릭 → `/reviews/` 정상 이동.
- 390px에서 홈 → 메뉴 열기 → 수강생 후기 클릭 정상 이동. 모바일 메뉴가 닫히고 후기 본문 표시.
- 후기 390px·1280px에서 잘림·가로 넘침 없음, 원문 버튼 3개 모두 높이 44px. 1024px의 데스크톱 메뉴 전환 지점에서도 메뉴와 카카오 버튼이 겹치지 않는다.
- 후기와 홈에 수강료 링크 없음. 후기 탐색 중 콘솔 오류·경고 0.
- 별도 읽기 검토에서 게임 본체 22파일 해시 불변, 기존 페이지는 메뉴와 명시된 문구 이외 본문 보존을 확인했다.

강사 설정의 복사는 격리된 컴포넌트 테스트로 확인했다. 실제 강사 계정 로그인이나 학생 OTP·업무 저장·알림 전송은 이번 검수에서 하지 않았다. dev/preview 서버는 후속 확인을 위해 유지한다.
