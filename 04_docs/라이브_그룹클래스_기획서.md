# 📚 하늘하늘중국어 — 라이브 그룹 클래스 기획서

> 대표님(최하늘 강사) 검토용 · 정리일: 2026-06-01
> 한 줄 요약: **"인강"이 아니라 "라이브 그룹 클래스 + 다시보기 + 숙제 피드백"으로, 우리 케어를 유지한 채 수입 천장을 올리는 첫 확장 모델.**

---

## 1. 왜 이걸 하려는가 (출발점)

- 1:1 수업은 **강사 시간 = 매출 상한**. 학생을 아무리 늘려도 하루 24시간이 천장.
- 그래서 **시간을 덜 쓰고 더 버는 구조**가 필요 → 그룹 클래스.
- 솔직한 동기: **불로소득(강사 시간 0의 매출 라인)을 만들고 싶다.** → 옳은 방향. 우리 로드맵 Tier 2~3에 이미 있는 길.

### ⭐ 중요한 전제 — 1:1은 이미 만석 (신규 못 받음)

현재 1:1은 자리가 꽉 차서 신규 학생을 받지 못하는 상태. 이게 두 가지를 바꿔요:

1. **단가를 올릴 결정적 근거** — 1:1 만석 = 수요 > 공급 = "가격이 낮다"는 신호.
   → **신규 1:1부터 +20% 인상 검토**가 그룹 클래스보다 더 빠르고 확실한 수입 증가일 수 있음
   (기존 학생 그대로, 신규만 인상). 그룹과 **병행**할 것.
2. **그룹 클래스가 "유일한 신규 입장 통로"** — 1:1이 닫혀 있으니, 하늘하늘에 들어오고
   싶은데 못 들어오는 신규 수요를 담는 **유일한 그릇**이 그룹 클래스. (지금은 이 수요를 돌려보내는 중)
   → 그룹 클래스를 해야 할 **더 강력한 이유**.

## 2. 이건 "인강"이 아니다 (중요)

대표님이 "인강 찍는다"고 생각했지만, 실제 설계는 **라이브 그룹 클래스**예요. 이 차이가 핵심입니다.

| | 일반 인강 (파고다·시원스쿨) | **우리 라이브 그룹 클래스** |
|---|---|---|
| 형태 | 녹화 영상만 판매 | **실시간 라이브 + 다시보기** |
| 케어 | 없음 (혼자 봄) | **숙제·녹음 피드백 있음** |
| 경쟁 | 자본 큰 대형사와 규모 싸움 | 우리 인격·케어로 차별화 |
| 우리 정체성 | ❌ 우리가 거부한 모델 | ✅ 우리 결과 맞음 |

→ **잘 고르셨어요.** 인강의 함정(케어 0, 대기업과 규모전)을 피하면서 수입을 올리는, 우리에게 가장 안전한 첫 확장입니다.

## 3. 클래스 한 사이클 구조

```
[1주차] 수요일 21:00  라이브 강의 (50~60분)
[2주차] 수요일 21:00  라이브 강의
[3주차] 수요일 21:00  라이브 강의
[4주차] 수요일 21:00  라이브 강의 + 숙제 부여
         │
         ▼ (숙제 제출 마감일 하루 고정)
[피드백 주] 3~5일 동안  녹음 숙제 받고 → 녹음으로 피드백 + 간단 코멘트
         │
         ▼
   녹화 영상은 10월까지 다시보기 가능
```

| 항목 | 내용 |
|---|---|
| 일정 | 매주 수요일 밤 9시, 월 4회 |
| 1회 길이 | 50~60분 |
| 가격 | **월 5만원** |
| 숙제 | 마지막 주 부여, **녹음 파일**로 제출 |
| 피드백 | **녹음 + 간단 코멘트**, 제출 후 **3~5일 내** |
| 다시보기 | 녹화 영상 10월까지 시청 가능 |

## 4. 수입과 정원 — 숫자로 보기

### 진짜 천장은 "강의실"이 아니라 "피드백 시간"

- **라이브 강의**: 20명이든 50명이든 항상 4시간 → 무한 확장 ✅
- **숙제 피드백**: 사람 수에 정비례 (1명당 10~20분) → 여기가 진짜 한계 ⚠️

### 정원 공식

> **최대 인원 = (피드백 기간에 쓸 시간) ÷ (1명당 피드백 시간)**
> ※ 1명당 시간은 안전하게 **20분**으로 계산 (짧게 잡으면 번아웃)

### 3~5일 피드백 기간 기준 정원·매출표

| 피드백 기간 | 하루 2시간 작업 | 하루 3시간 작업 |
|---|---|---|
| 3일 | **18명** (90만원) | **27명** (135만원) |
| 5일 | **30명** (150만원) | **45명** (225만원) |

→ **"5일 × 하루 3시간 = 45명"이 이 모델의 건강한 상한.** 그 이상 받으면 기간을 넘기거나 뒷사람 피드백 품질이 떨어집니다.

## 5. ⚠️ 가장 조심할 것 — "시간 내면 된다"는 생각

이 한 가지가 모델을 망칠 수 있어요.

- "시간 무제한으로 쓰면 된다" → **1:1의 시간 천장 문제를 그룹 안으로 다시 끌고 옴.** 레버리지가 사라지고 "싸게 일 더 하는 구조"가 됨.
- 우리 메모리에도 빨간불: *"무제한 응대 → 번아웃 위험"*

**대신 이렇게:**
1. **정원을 정한다** (무제한 ❌) — 피드백 기간 안에 끝낼 수 있는 만큼만.
2. **숙제 제출 마감일을 하루로 고정** — 안 그러면 피드백 기간이 무한정 늘어남.
3. **"제출 후 5일 내 피드백" 약속** — 학생에겐 신뢰, 대표님에겐 방어선.
4. **하루 피드백 2~3시간 캡** — 그 이상은 품질 떨어지고 지침.

## 6. 이 클래스의 역할 — 신규 수요의 "유일한 입장 통로"이자 완결된 목적지

1:1이 만석이라 그룹 클래스는 단순 "맛보기"가 아니라 **신규 학생이 하늘하늘에 들어올 수 있는 유일한 문**이에요. 그래서 **그 자체로 만족스러운 완결된 목적지**로 설계해야 합니다 (1:1 가기 전 단계 ❌).

**이 클래스가 만드는 가치:**

- 🚪 **신규 수요 수용** — 지금 돌려보내고 있는 "들어오고 싶은데 못 들어오는" 사람들을 담음
- 💰 **새 매출 라인** — 1:1 천장 위에 얹는 추가 수입
- 📖 **자체 교재 베타 테스트장** — 만든 교재를 그룹에서 검증 후 다듬기
- ⭐ **후기·잠재고객 자산** — 광고 없이 팬을 모으는 채널
- 🔁 **멤버십(MRR)으로 이어질 씨앗** — 반복 매출 구독 모델의 출발점

### 1:1 우선권은 "약속"이 아니라 "보너스"

1:1 자리는 **언제 날지 알 수 없다** (학생 졸업·이탈 시 가끔). 그러니:

> ❌ "3개월 후 1:1 자리 보장" (거짓 약속 → 못 지키면 신뢰 붕괴)
> ✅ **"1:1 자리가 나면 그룹 수강생에게 가장 먼저 안내드려요"** (정직한 우선권)

→ 1:1 우선권은 **메인 약속이 아니라 보너스**로만 깔아두기. 자리 나면 행운, 안 나도 그룹에서 충분히 만족하도록.

## 10. 한 줄 결론

> **1:1이 만석이라 그룹 클래스는 "신규가 들어올 유일한 문"이자 완결된 목적지다. 인강이 아니라 "라이브 그룹 클래스"라서 우리 케어를 지키며 수입을 올린다. 진짜 천장은 "피드백 시간"(꽉 찬 1:1 위에 얹는 시간이라 더 빠듯)이니, 3~5일 피드백 기간을 상품 사양으로 박고 월 정원은 12~15명으로 보수적으로 시작해 실측 후 키워라. 동시등록 유인은 "할인"이 아니라 "패키지 가격 + 가치 추가"로 풀어 우리 톤을 지켜라. 1:1 우선권은 약속이 아니라 보너스로만 깔아라.**

## 11. 🗓️ 7~8월 첫 런칭 — 확정 구조

강사님이 계획한 실제 런칭 형태. (정리: 2026-06-01)

### 등록 구조

7~8월을 **한 번에 광고**, 등록은 3종으로 따로 받음:

| 등록 유형 | 가격 | 비고 |
|---|---|---|
| **7+8월 동시등록 (패키지)** | 2개월 묶음 가격 (정가 10만원에서 혜택) | "할인"이라 부르지 않고 **"패키지 가격"** + 가치 추가 |
| 7월만 | 5만원 | |
| 8월만 | 5만원 | 7월 안 들은 신규도 따라올 수 있게 설계 |

- **각 월 최대 정원 별도 운영** → 동시등록자는 7·8월 양쪽 자리를 차지.
  예) 7월 정원 = (7월만) + (동시등록), 8월 정원 = (8월만) + (동시등록).
- **월별 캡이 핵심 안전장치**: 기수가 누적돼 부하가 폭증하는 걸 자동으로 막음.

### 동시등록 유인 — "할인" 대신 "패키지 + 가치 추가" (추천안)

우리 정체성(할인·이벤트 ❌, "안 팔려는 톤")과 충돌 방지:

- ✅ **"할인" 단어 안 씀 → "2개월 패키지 가격"으로 제시**
- 💡 **가치 추가 = "더 준다" (강사 시간 비용 0 위주로 추천)**:

| 혜택 | 강사 시간 부담 | 비고 |
|---|---|---|
| ⭐ **1:1 자리 우선권** | 0 | 만석이라 가장 강력. 비용 없음 |
| ⭐ **다시보기 연장** (10월 → 연말) | 0 | 유튜브 링크 기간만 연장 |
| ⭐ **전용 복습 자료** (핵심표현 요약 PDF/녹음) | 일회 제작 | 자체 교재 자산화와 연결 |
| (선택) 8월 보너스 피드백 1회 | ⚠️ 시간 듦 | 여유 있을 때만 — **번아웃 주의, 기본은 제외 권장** |

→ **추천 묶음: 우선권 + 다시보기 연장 + 복습 자료** (시간 비용 거의 0, 체감 가치 큼).

### 7월 vs 8월 콘텐츠 테마 (추천안)

각 월 **독립 완결**(8월만 등록자도 OK) + **동시등록 시 시너지**. 우리 차별점을 테마화:

| 월 | 테마 | 차별점 연결 |
|---|---|---|
| **7월** | **"한국인이 막히는 발음·성조 집중"** | 차별점 1(한국인 시선) + 3(동북 발음) |
| **8월** | **"드라마로 배우는 진짜 회화 표현"** | Job 2(덕질러) + 차별점 2(재미) |

- **독립성**: 7월=발음, 8월=표현 → 따로 들어도 완결.
- **시너지**: 7월 발음 토대 → 8월 그 발음으로 드라마 표현 = 동시등록이 자연스러운 "정석 코스".
- 8월 "드라마 회화"는 **덕질 후킹**이라 인스타 광고 카피로도 강력.

### 1:1 우선권 안내 문구 (추천 카피)

> **"1:1 정규 수업은 지금 정원이 가득 차서 신규를 못 받고 있어요. 혹시 자리가 나면, 그룹 클래스 함께한 분들께 가장 먼저 안내드릴게요. 언제 날지는 저도 약속드릴 수 없지만, 순서는 확실히 지켜요. :)"**

- 만석을 솔직히 공개 → 희소성·신뢰(안 팔려는 톤) / 약속 ❌ 우선권 ⭕ / "언니" 톤

### 캘린더 주의

- 7월 4회 + 숙제 피드백(3~5일)이 **7월 말~8월 초**에 걸림.
- → 8월 라이브와 겹치지 않게 **"피드백 주"를 일정에 버퍼로 확보** (예: 7월 4주차 강의+숙제 → 피드백 → 8월은 둘째 주부터, 또는 한 기수 = 4주 강의 + 1주 피드백 = 5주 사이클).

### 최종 점검 (런칭 전 강사님 확정)

제안서상 모두 추천안으로 채움 — 강사님이 OK/수정만 하면 됨:
- 동시등록 가치 추가 → **우선권 + 다시보기 연장 + 복습 자료** (추천)
- 월 정원 → **15명**(불안하면 12) (추천)
- 7·8월 테마 → **7월 발음·성조 / 8월 드라마 회화** (추천)
- 1:1 우선권 문구 → 위 카피 (추천)
- 결제·환불·플랫폼 → 확정

## 12. 💸 환불 정책 (확정)

> 원칙: **명확·공정·간단.** "안 팔려는 톤"이라 인색하지 않되 강사 보호. 등록 페이지에 **먼저 공지**해 신뢰 자산으로.

### 환불표 (회차 비례 — 5만원 ÷ 4회 = 회당 12,500원)

| 시점 | 환불액 |
|---|---|
| **첫 수업 전** | **100% (5만원)** |
| 1회차 수강 후 | 미수강 3회분 = **37,500원** |
| 2회차 수강 후 | 미수강 2회분 = **25,000원** |
| **3회차 이후** | **환불 없음** (절반 이상 수강) |

→ "들은 회차만 차감" — 누구나 납득, 계산 쉬움. (학원법 환불 기준 정신과 일치)

### 특수 케이스
- **동시등록(패키지)**: 7월 진행 중이라도 **8월은 미개강 → 8월분 전액 환불 가능.** 단 패키지 보너스는 환불 시 소멸.
- **녹화 다시보기**: **환불 시 접근 종료** (환불받고 녹화만 보는 것 방지) — 등록 안내에 명시.
- **법정 청약철회**: 결제 후 7일 이내 & 첫 수업 전이면 단순 변심도 100% (전자상거래법) — 위 "첫 수업 전 100%"에 포함.
- **결석**: 라이브 못 오면 **유튜브 다시보기로 대체** (환불 사유 아님).

## 13. 🛠️ 플랫폼 & 운영 도구 (확정)

| 기능 | 도구 | 비고 |
|---|---|---|
| **라이브 강의** | **줌(Zoom)** | 클라우드 녹화 활용 |
| **다시보기** | **유튜브 "일부공개"** | 10월까지 링크 제공, 이후 비공개 전환 |
| **숙제·피드백** | **채널톡 (1:1)** | 녹음은 사적이라 단톡 ❌ → **1:1 채널**로 주고받음 |
| **등록 문의** | **채널톡** | 문의 → 안내 |
| **결제** | **기존 사용 중인 결제 서비스 링크** | 채널톡으로 결제 링크 발송 |
| **공지** | **채널톡** | |
| **커뮤니티** | (보류) | 아직 계획 없음 — 향후 검토 |

### 운영 메모
- **채널톡이 허브**: 등록 문의 · 결제 안내 · 숙제 수합 · 피드백 · 공지 모두 채널톡 1:1에서 처리.
- ⚠️ **추적은 수동**: 채널톡은 "누가 제출/피드백 받았는지" 자동 추적이 없음. 15명까진 **체크리스트로 수동 관리** 충분. 단 정원이 커지면(2기 이후) 관리 부담 ↑ → 그때 자체 시스템 통합 재검토.
- 운영비 ≈ 월 2만원대(줌) + 채널톡 요금제 / 유튜브·결제링크는 기존 활용.
