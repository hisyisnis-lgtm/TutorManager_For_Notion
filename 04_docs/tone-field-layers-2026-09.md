# 성조게임 들판 레이어

2026-09-08 사용자 피드백: 가려진 부분까지 완성된 개체를 레이어로 합성하고, 종이 질감·얼룩을 없앤 깔끔한 벡터 그래픽을 사용한다. 원래 집의 형태와 개체 배치를 유지하며 굴뚝은 집과 같은 투시를 사용한다.

## 현재 자산과 합성

- 원본 참조: `pwa/public/game/field-reference.png`.
- 현재 자산: `pwa/public/game/field-parts-vector/`의 `backdrop.svg`, `trees.svg`, `shrubs.svg`, `house.svg`, `chimney.svg`.
- 장면 좌표·atlas viewBox·회전 중심: `pwa/src/game/fieldScene.js`.
- 렌더러: `pwa/src/game/screens/FieldIllustration.jsx`.
- 순서: 하늘/들판 → 뒤 덤불 → 완전한 나무 4개 → 굴뚝 → 집 → 굴뚝 연기 → 앞 덤불.
- atlas viewBox는 개체 전체와 투명 여백을 포함한다. 다른 오브젝트에 가려질 부분도 남겨 두며, 실제 가림은 합성 순서로 처리한다.
- 나무는 줄기 바닥을 중심으로 회전한다. 연기·나무 모션은 모션 감소 설정과 탭 비활성화를 따른다.
- `field-parts/`, `field-parts-v2/`, `fieldLayers.generated.js`는 이전 이미지 기반 자산이다. `prepare-tone-field-layers.py`와 Blender 평면 렌더 스크립트도 이전 버전용이며 현재 장면을 재생성하는 데 사용하지 않는다.

## 자산 제작

SVG는 원본의 주요 곡선·좌표를 따라 직접 작성한 단색 path·원·사각형이다. 래스터 이미지를 SVG에 임베드하거나 노이즈·필터·그라디언트로 질감을 재현하지 않는다. 지붕·굴뚝의 깊이는 소수의 단색 면으로만 구분한다. SVG atlas의 크기와 배치·회전 중심은 이전 장면을 유지한다.

집 전체를 다른 외형으로 재생성한 후보는 사용자가 제외했다. 벡터 집은 원본의 낮고 넓은 비율, 지붕 능선·처마, x700~780/y627~747의 아치문, 중심(860,656)/반지름38의 원창을 유지한다. 덤불 뒤에 가려졌던 벽도 완전히 그렸으므로 원본 이미지의 덤불 흔적을 가리기 위한 외곽 클리핑은 더 이상 필요 없다.

굴뚝은 원본 지붕과 같이 깊이 방향이 좌상단으로 향하는 얕은 옆면·윗면을 사용한다. 밑부분은 완전한 기둥 형태로 남기고, 앞에 그리는 지붕이 자연스럽게 가린다.

이전 PNG를 복원할 때 사용한 생성 프롬프트·alpha 검증은 `field-parts-v2/` 메타데이터에 남아 있다. 제외된 집 후보는 `05_assets/Blender/tone-field/references/`에 보관한다. 이 PNG들은 현재 렌더러에서 불러오지 않는다.

독립 편집용 전체 장면은 `05_assets/Vector/tone-field/field-scene.svg`에 정지 상태로 합성한다. 앱에서는 개체별 SVG와 기존 CSS 애니메이션을 계속 사용한다.

합성 검수는 나무 회전 양 끝에서 밑동·지붕·앞 덤불 경계가 자연스럽게 유지되는지 확인한다. 파일 확장자만 확인하지 않고 SVG 내부에 래스터·필터·그라디언트가 없는지도 검사한다.

## 인게임 숲속 연습 빈터

집에서 나와 숲에서 성조를 연습한다는 콘셉트에 맞춰 `GameScreen`만 `FieldBg scene="forest"`를 사용한다. 타이틀·모드 선택·난이도는 기존 집 앞 들판을 유지한다.

`ForestIllustration.jsx`는 완전한 나무 SVG 7개를 뒤·중간·앞 순서로 배치하고, 앞 수풀 8개가 밑동을 자연스럽게 가린다. `forest-backdrop.svg`에는 중앙 잔디 빈터를 그린다. 사용자 피드백으로 짧은 오솔길과 오른쪽 큰 나무 뒤에서 밑동만 떠 보이던 작은 나무 1개를 제거했다. 앞의 밝은 나무는 원래 배치를 유지한다. 집·굴뚝·연기는 없으며 기존 SVG 그림체와 나무 흔들림·탭 비활성·모션 감소 설정을 유지한다.

## 실내 SVG

추가 사용자 요청으로 `RoomBackdrop.jsx`의 벽·벽 하단·몰딩·바닥·창문도 실제 SVG 도형으로 전환했다. 반듯한 벽과 정면 사각창을 유지하고, 나뭇결·그라디언트·빛 얼룩은 제거했다. 바닥에는 넓은 판재의 이음선만 SVG pattern으로 남긴다. 바닥 경계 144px와 캐릭터 물리 영역 146px는 유지한다. 작은 화면의 창문 위치는 기존 컨테이너 쿼리를 따른다.

`05_assets/Vector/tone-field/room-scene.svg`는 390×844 기준의 독립 편집용 실내 배경이다. 앱에서는 반응형 SVG 컴포넌트를 사용하며 캐릭터·UI·공의 동작은 기존 구조를 따른다.
