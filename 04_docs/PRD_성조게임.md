## 0. 한 줄 정의

**중국어 단어의 각 한자 성조를 듣고·보고 시간 안에 맞히는 모바일 웹 게임.** 하늘하늘중국어(1인 회화 튜터링)의 **무료 유입 깔때기**이자, 강사의 공부법("병음 없이 성조만 직접 표기")을 게임으로 옮긴 독립 제품.

- 이름: 성조다락방 (타이틀 태그라인 "매일매일 성조키우기")
- 형태: 학생앱과 **분리된** 독립 라우트 `/game/tone`. 게스트로 바로 플레이, 카카오·구글 로그인 시 기록 동기화.
- 출구: 게임 안 '놀러가기'로 인스타·유튜브·블로그·무료상담 페이지 연결.

## 1. 배경과 목표

### 왜 만들었나
1. **강사 차별점의 체험판**: "왜 한국인이 성조에서 막히는지 아는 강사"라는 서비스 정체성을 말 대신 게임으로 보여준다. 소개 화면 문구가 곧 근거: *하늘쌤의 공부법에서 시작했어요 — 유학 시절, 병음 없는 중국어에 성조를 직접 적어가며 회화를 익혔던.*
2. **콘텐츠 채널 → 상담 유입의 중간 고리**: SNS에서 게임으로, 게임에서 채널·상담으로 순환시키는 자생 마케팅 표면.
3. **수강생 보조 학습**: 학생앱과 분리됐지만 학생도 같은 URL로 쓴다(재도전·복습).

### 목표 (v1, 운영 중)
- 첫 진입에서 **설명 없이** 한 판을 끝내게 한다(온보딩 원칙 "게임을 해보기 전에는 아무것도 설명하지 않는다").
- 매일 돌아올 이유를 준다: 스트릭·스테이지 사다리·승급시험·업적·오답 노트.
- 게임 안에서 채널로 나가는 출구 클릭을 만든다(측정 가능한 유일한 전환 지표).

### 비목표 (의도적 제외)
- 예문·문장 단위 문제 (2026-07-15 전면 철회)
- 재화·꾸미기 상점 (철회, `game_currency.md`)
- 단어 관리자 페이지 (CSV 갈아끼우기 유지)
- 점수 정합성 서버 검증 (게스트→회원 병합이 깨져 금지, `game_score_integrity.md`)
- 학생 계정과의 전화번호 연결·SMS OTP (소셜 로그인으로 대체)
- 배치고사 (승급시험으로 대체, 전면 제거)
- 리더보드 (별도 기능으로 보류, 부정행위·프라이버시 결정 선행)

## 3. 핵심 루프

```
스플래시 → 타이틀 → (첫 방문: 소개 3장 → 튜토리얼 → 입문 1 한 판 → 닉네임) → 홈
홈 → 모드 선택 → 난이도(15스테이지) | 무한 | 테마 | 트레이닝 → 카운트다운 → 게임 → 비트(게임오버/신기록 → XP → 승급/해제) → 결과 → 다시하기 | 다음 스테이지 | 홈
```

### 한 판의 규칙 (게임 메커니즘)
- 카드에 **한자만** 보인다(병음 숨김). 현재 글자를 강조하고, 그 글자의 성조(1·2·3·4·경성) 키를 **시간 안에** 탭한다.
- 제한 시간은 콤보가 쌓일수록 줄어든다(단어당 7초 → 3초). 급별 기본 배수: 입문 ≈30초 / 실전 ≈20초 / 고수 ≈10초 감각.
- **오답**: 누른 키만 빨갛게 흔들리고 **정답은 공개하지 않는다**(남은 시간에 계속 시도). 콤보만 끊긴다.
- **시간초과**일 때만 정답(성조·병음) 공개 + 빨간 글로우. **정답**은 초록 글로우 + 발음 재생.
- 힌트: **발음 듣기**(TTS, 힌트 사용 시 '완벽' 아님) · **정답보기**(건너뛰기).
- 3성 변조(3+3 → 앞 글자 2성처럼)와 연음은 마크로 표시한다(`lianyin.js`, 하늘쌤 규칙 = '연음').
- 판다 코치가 상황별 한 줄을 말한다(유도·정답·콤보·오답·시간초과). 오답 때 정답을 말하지 않는다.
- 점수·콤보·최고점은 **스테이지 단위**로 기록한다(입문 4의 신기록은 입문 4끼리만 비교).

## 5. 진행과 보상

### 5.1 스테이지 사다리
- 별 3개 = 한 판 최고점의 1/3·2/3·3/3 (콤보 조건 없음).
- 잠금: 급 안에서는 직전 스테이지 별 1개 이상, **급 경계는 이전 급 5스테이지 전부 별 1개 이상**.
- 결과 화면에서 다음 스테이지가 열려 있으면 `[다시하기 | 다음 스테이지]` 분할 CTA.

### 5.2 레벨(XP)과 등급(rank) — 두 축
| 축 | 오르는 방법 | 표시 |
|---|---|---|
| 레벨 Lv.N | 플레이로만. XP = 점수 + 정답×3 + 신기록 100 (일반·무한·테마만, 트레이닝 제외). 상한 없음 | 홈 HUD 게이지, 프로필 |
| 등급 | **승급시험 합격으로만** (자동 승급·강등 없음). 입문 → 실전 → 고수, 엠블럼 브론즈·실버·골드 | 홈 HUD 엠블럼, 내 등급 화면 |

승급시험: 현재 급 풀에서 **20문제**, 정답률 **80%** 합격. 첫 오답 즉시 확정(정답 공개 후 다음). 타이머 유지. 불합격 시 현재 밴드 XP 15% 차감(등급 base 아래로는 안 내려감). 시험은 기록·스트릭·업적에 반영하지 않는다.

### 5.3 스트릭
하루 한 판이면 +1. 티어 라벨 = 불씨(1) → 불꽃(3) → 활활(7) → 이글이글(14) → 불기둥(30). 끊기면 0(꺼진 재). 보호권(freeze)은 스트릭 시트에서 관리.

### 5.4 업적 (15+)
카테고리: 시작 · 점수·콤보 · 모드 해제 · 단어 마스터 · 연속 학습 · 성조·복습. 예: 첫걸음, 열 판 채움, 천 점 클럽, 콤보 마스터, 완벽한 한 판, 실전 승급, 무한의 문. 달성 시 축하 오버레이 1회.

### 5.5 오답 노트 (`noteLeft` 카운터)
- 등록: 한 번이라도 '완벽하지 않은' 결과(오답·시간초과·건너뛰기·정답보기·힌트 후 정답). 모드 무관.
- 졸업: 정답(무실수·힌트 없음) **3번 누적**(연속 아님). 노트 안에서 또 틀리면 +1(최대 3).
- 화면: 오답 노트 탭에 단어·병음·뜻·게이지 n/3·발음 듣기. '복습 하기'로 그 단어들만 한 판.

## 8. 계정과 데이터

| 구분 | 게스트 | 회원 |
|---|---|---|
| 인증 | 없음(기기 로컬 `tg_guest_id`) | 카카오·구글 OAuth (Worker `/game/auth/*`, JWT 60일, sub = D1 UUID) |
| 저장 | localStorage 키 `game_*_<token>` | Cloudflare **D1** `game_users.game_data`(JSON, 100KB 상한) + 로컬 캐시 |
| 동기화 | — | 로그인 시 게스트→회원 병합(**최대값 머지**, sum 금지), push 전 반드시 pull |
| 닉네임 | 랜덤(형용사+동물) | 로그인 직후 1회 입력(제공자 이름 프리필), 1~12자, 서버 검증 |

- 저장·정체성은 `gameStore.js`(identity 추상화) 한 곳을 지난다. 새 기능은 이 위에 얹는다.
- Notion 의존은 완전히 제거됐다(2026-07 D1 이전). 단어 CSV만 빌드 타임에 읽는다.
- 보안: OAuth state는 HMAC 서명 무상태(colo 문제 해결), 리다이렉트는 호스트 정확 일치, 인증 오류 시 세션 정리. 로그인 CSRF 방어는 저위험으로 보류 중.

## 10. 비기능 요구사항

- **성능**: 게임은 지연 로드 청크(약 400KB). TTS mp3·BGM은 사전 생성 정적 파일. iOS는 오디오 엘리먼트 1개 고정·100dvh(`bug_ios_game_audio_viewport.md`).
- **접근성**: 텍스트 토큰 대비 WCAG AA(SUB 4.7 · STEEL 4.9 · TAB 4.9). 터치 타겟 44px. 모션 최소화 설정 존중.
- **호환**: 카카오 인앱 브라우저(레터박스 폭 orientation 분기), 안드로이드 파일 업로드 무관.
