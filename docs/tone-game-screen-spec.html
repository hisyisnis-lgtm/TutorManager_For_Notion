7이 문서에 미수록된 화면

전환 연출·특수 상태라 정지 스크린샷이 어렵거나 이번 캡처에서 제외된 화면.

· 스플래시(브랜드 컷→게임 로고)          · 카운트다운(3·2·1 오버레이)
· 소개 ①②③ (첫 방문 온보딩)             · 배치테스트(첫진입 실력 테스트)·배치 결과
· 승급시험 안내·시험 결과(ExamResult)     · 무한 모드 시작 모달·게임오버 비트·신기록 비트
· 등급 승급 연출(RankUpReveal)           · 모드 해제 연출(ModeUnlockReveal)
· 단어 숙련도(MasteryScreen 하위 상세)    · 닉네임 설정/수정 모달
· 정답/오답/시간초과 공개 상태            · 콤보 브레이크·타격 연출 순간
